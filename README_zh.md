# IDASlicer

IDASlicer 用于把二进制中的某些部分（函数、段或任意选区）提取、"切片"到新的 IDA 数据库或 `.seg` 文件中，方便从大型二进制里切出可单独分析的一块。

[English Version](./README.md)

## 功能特点

- **加入切片列表**（在反汇编视图右键 → `Add to Slicer/`）：
  - **Function**：加入该函数（IDA 没定义函数时，加入从光标处能走到的代码）以及它引用的数据，不跟进对其他函数的调用。
  - **Selection** 或 **Current segment**。与已有条目重叠的范围会并入该条目；只是首尾相接的范围仍各占一行。
  - **Function recursively**（递归添加）：加入该函数，以及它引用的所有代码/数据范围，并递归跟进。相邻或重叠的范围会合并成一条条目——扫描结果之间会合并，也会和列表中已有的范围合并，所以与已有条目相邻的发现会把该条目扩展，而不是新增一行。真正的空隙则原样保留，且不会跨段合并。中途取消扫描时，已找到的部分照样加入，并提示列表不完整。
- **切片管理面板**（`Edit → Plugins → IDASlicer`）：检查、编辑（名称、范围、权限、类型、对齐）或删除条目；Size 列显示每个范围的大小，Ref 列显示把该范围引入列表的那个引用（扫描起点或手工添加的范围为空）。单击 Start、End 或 Ref 单元格可跳转到对应地址。编辑一个递归条目的范围时会对新范围重新扫描引用。列表按输入文件 MD5 保存在 `idaslicer_config.json` 中。
- **设置**（面板上的按钮）：调整引用落到无大小数据上时向后粘连相邻项的距离，以及是否收集已命名的数据。全局保存在 `idaslicer_config.json` 中。
- **创建 IDA 数据库 (9.1+)**：生成只包含所选切片的新 `.i64`，并按文件类型（ELF/PE/Mach-O）和架构（x86/x64/ARM/ARM64）自动选择模板。导出前（这里和导出 `.seg` 文件都一样）会合并互相重叠的条目、跳过空范围，保证任意两个段不共用地址；列表本身不变。源数据库里没有值的字节（BSS、extern）在切片里也保持没有值。某个范围加不进去时，数据库照样保存，并列出缺失的范围。
- **导出 `.seg` 文件**：每个条目连同段名、范围、权限、类型/对齐、字节以及用户定义的符号名一起保存。可选择**合并**为单个文件，便于批量传输与导入。
- **导入 `.seg` 文件 (9.1+)**：把单个或合并的文件导回数据库，恢复字节、段属性和符号名。文件只按普通数据读取，构造过的 `.seg` 无法借此执行代码。与现有段重叠时，可覆盖数据或在空隙处创建新段。导入的范围会和切片列表整体合并一次——跨所有选中文件，并且和列表中已有的范围一起合并——所以与已有条目相邻或重叠的导入会把该条目扩展，而不是新增一行。

## 要求

- **IDA Pro 9.1+**：创建/导入数据库功能需要（使用 `ida_domain` API）。其他功能在更早的 9.x 上也可用。
- **PySide6**：现代 IDA Pro 已自带。

## 安装

将整个文件夹复制到 IDA 插件目录：
- **Windows**: `%AppData%\Hex-Rays\IDA Pro\plugins`
- **Linux/macOS**: `~/.idapro/plugins`

## 工作原理

- **数据库切片**：从 `obj_minis/` 复制一个迷你模板，再通过 `ida_domain` API 运行后台进程，在不关闭当前会话的情况下重建段、字节、属性与名称。
- **`.seg` 文件**：是 pickle 序列化的字典，保存元数据、字节和收集到的符号名，因此不依赖脆弱的文件名解析。导入时自动区分单个文件与合并文件，并把所有信息重新应用（用 `ida_name` 设置名称、在新建段上设置类型/对齐），同时处理重叠冲突。
